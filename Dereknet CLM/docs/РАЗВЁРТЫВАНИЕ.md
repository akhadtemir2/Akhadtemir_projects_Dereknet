# Развёртывание — версия для разработчика

Ставим CLM на аккаунт `office@dereknet.com` (или `clm@dereknet.com`).
Занимает ~20 минут. Для не-технической версии см. [ПЕРЕНОС_НА_DEREKNET.md](ПЕРЕНОС_НА_DEREKNET.md).

---

## 0. Разовая подготовка

```bash
npm install -g @google/clasp
clasp login          # в браузере войти как office@dereknet.com
```

Если `clasp login` ругается — включить Apps Script API:
https://script.google.com/home/usersettings → **Google Apps Script API: ON**

---

## 1. Создать проект и залить код

```bash
git clone https://github.com/akhadtemir2/Akhadtemir_projects_Dereknet.git
cd Akhadtemir_projects_Dereknet

clasp create --title "Dereknet CLM" --type sheets --rootDir src
clasp push -f
clasp open --addon        # откроет привязанную таблицу
```

Что произошло:
- создана Google Таблица `Dereknet CLM` во владении `office@dereknet.com`;
- к ней привязан скрипт, `.clasp.json` записан локально (в `.gitignore`);
- залито 11 `.gs` + `Index.html` + `appsscript.json`.

`appsscript.json` уже содержит `enabledAdvancedServices: Drive v3` и все oauthScopes —
вручную подключать службы не нужно.

> Порядок файлов: Apps Script выполняет объявления верхнего уровня в алфавитном
> порядке имён. Числовые префиксы `01_` … `11_` это обеспечивают. Не переименовывать.

## 2. Инициализация (в браузере, ~3 минуты)

В открывшейся таблице обновить страницу → появится меню **📄 CLM**.

| Действие | Что делает |
|---|---|
| **CLM → 🛠 → 🚀 Запустить мастер установки** | Поле оставить пустым → создаст папку `Dereknet CLM` в Моём диске. Или вставить ID существующей папки / Общего диска |
| Экран OAuth → «Дополнительные настройки» → «Перейти к Dereknet CLM (небезопасно)» | Приложение не в маркетплейсе, это ожидаемо |

Мастер создаёт: 6 папок, листы `Журнал` / `Реестр договоров` / `Справочник ошибок`,
триггеры (`processInbox` 5 мин, `cleanupStuckFiles` 1 ч, `dailyDigest` 09:00).
Сама таблица становится журналом — вторая не создаётся.

Затем:

```
CLM → 🛠 → 🔑 Указать ключ OpenAI          # новый ключ, старый отозвать
CLM → 🛠 → 📧 Указать email ответственного
```

Положить в созданную папку **«6. Шаблоны»**:
- шаблон NDA как **Google Документ** (не `.docx`),
- PNG подписи директора.

```
CLM → 🛠 → 🔍 Найти шаблоны и подпись
```

## 4. Веб-приложение

```bash
clasp deploy --description "v5.0"
clasp deployments          # взять deploymentId
```

Права доступа `clasp` не выставляет — открыть в браузере:
**Начать развёртывание → Управление развёртываниями → ✏️**

| Поле | Значение | Почему |
|---|---|---|
| Запуск от имени | **Я** | Сотрудникам не нужны права на Drive |
| Доступ | **Все в организации Dereknet** | Только `@dereknet.com` |

URL: `https://script.google.com/a/macros/dereknet.com/s/<id>/exec`

```
CLM → 🔗 Открыть форму заявки   # вставить URL, сохранится в WEBAPP_URL
```

## Дальнейшие правки кода

```bash
# правка в src/, затем:
npm test && clasp push -f
git commit -am "..." && git push
```

Для веб-приложения после `clasp push` нужен новый деплой:

```bash
clasp deploy -i <deploymentId> --description "v5.1"
```

Без `-i` создастся новое развёртывание с **новым URL** — старая ссылка у сотрудников
перестанет обновляться. Всегда обновлять существующее.

## Грабли

| Симптом | Причина |
|---|---|
| `clasp push` → `User has not enabled the Apps Script API` | script.google.com/home/usersettings → API: ON |
| Меню 📄 CLM не появилось | Не обновлена вкладка таблицы (F5) |
| `Drive is not defined` | `appsscript.json` не залит — проверить `clasp push` и `rootDir: src` |
| Форма → «Отказано в доступе» | Развёрнута с «Только я» |
| Триггеры молчат | Владелец не прошёл OAuth — запустить `processInbox` вручную из редактора |
| `ПУСТЫЕ_ПЛЕЙСХОЛДЕРЫ` при генерации | В шаблоне есть `{{TOKEN}}`, которого нет в `06_Render.gs`. Код специально не выпускает такой договор |
| Договор с `—` вместо значений | Поле пришло пустым; `fillSection_` подставляет `—` осознанно |
